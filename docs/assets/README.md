Put portfolio screenshots here.

## Triage BEV player

Save a PNG as **`triage-bev.png`** (recommended ~1600px wide):

1. Open the web UI on a dense scene (`scene-0655`) with an `ID_SWITCH` selected
   so the yellow highlight + “was tr → now tr” panel are visible.
2. Capture the window (macOS: `Cmd+Shift+4`, then space for window shot).
3. Copy into this folder:

```bash
# example
cp ~/Desktop/Screenshot*.png docs/assets/triage-bev.png
```

The root `README.md` embeds this file when present.
